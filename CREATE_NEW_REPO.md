# 🍄 CHAMPIRUG - REPOSITORIO INDEPENDIENTE

## 🎯 PASOS PARA CREAR REPOSITORIO SEPARADO:

### 1. 🌐 Crear repositorio en GitHub
1. Ve a: https://github.com/Dovaskul
2. Click "New repository" (botón verde)
3. **Repository name**: `champirug-game`
4. **Description**: `🍄 Champirug - HTML5 mushroom game with custom sprites`
5. **Public** ✅ (para GitHub Pages gratis)
6. **NO** marques "Add a README file" (ya tenemos archivos)
7. Click "Create repository"

### 2. 🔗 Conectar tu carpeta local
```bash
cd C:\Users\chema\VSCODE\champirug
git remote add origin https://github.com/Dovaskul/champirug-game.git
git push -u origin main
```

### 3. ⚙️ Activar GitHub Pages
1. En tu repositorio → Settings (pestaña)
2. Scroll down hasta "Pages" (menú izquierdo)
3. **Source**: "Deploy from a branch"
4. **Branch**: "main"
5. **Folder**: "/ (root)"
6. Click "Save"

### 4. 🎮 ¡Tu juego estará online!
- **URL**: `https://dovaskul.github.io/champirug-game/`
- **Tiempo**: 5-10 minutos para activarse
