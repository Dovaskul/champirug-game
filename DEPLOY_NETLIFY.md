# 🚀 CÓMO SUBIR CHAMPIRUG A NETLIFY

## Método 1: Drag & Drop (MÁS FÁCIL)
1. Ve a https://netlify.com
2. Regístrate gratis
3. Click "Sites" → "Add new site" → "Deploy manually"
4. Arrastra toda la carpeta `champirug` al área de drop
5. ¡Listo! Te da una URL automática

## Método 2: Desde GitHub
1. Sube tu código a GitHub primero
2. En Netlify: "Add new site" → "Import from Git"
3. Conecta tu repositorio
4. Deploy automático en cada cambio

## ✅ Ventajas:
- SSL automático (HTTPS)
- CDN global
- Formularios gratuitos
- Funciones serverless
